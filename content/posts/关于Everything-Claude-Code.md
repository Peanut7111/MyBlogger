## 什么是 Everything Claude Code

## 主要特点

- **技能丰富**：涵盖前端、后端、代码审查、测试等多种领域
- **即插即用**：安装后即可在 Claude Code 中使用
- **持续更新**：社区活跃，不断有新技能加入

## 如何使用

1. 在 Claude Code 中安装你需要的技能
